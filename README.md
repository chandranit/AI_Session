# AI Session Template Repository

This branch (`main_template`) serves as a starting template for new feature/session branches.

## 📁 Included Template Files

- `.agents/AGENTS.md`: AI assistant guidance and git commit rules.
- `.env`: Environment variables configuration (API keys, URLs).
- `.venv/`: Python virtual environment.
- `.gitignore`: Standard git ignore patterns.
- `commit_message_format.md`: Standard reusable git commit format guidelines.
- `README.md`: Project description template.

## 🚀 How to Create a New Branch from this Template

```bash
# 1. Checkout the template branch
git checkout main_template

# 2. Create your new branch
git checkout -b session_X  # or feature/your_feature_name
```

# Repository Rules & Customizations

## Git Commit Standard
Whenever the user asks to commit changes, follow the format defined in `commit_message_format.md`:

Format:
```text
<type>(<scope/branch>): <short summary in imperative present tense>

- <Action verb> <file_name_1>: <crisp description of change 1>
- <Action verb> <file_name_2>: <crisp description of change 2>
```

Types: `feat`, `fix`, `docs`, `refactor`, `style`, `test`.
